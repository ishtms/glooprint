Title
GlooPrint - Blueprint Formatter

Product type and category
Tools & Plugins - Engine Tools

Description
Blueprints get messy pretty quickly. GlooPrint helps with that - press F and it arranges the graph for you.

Select a node first if you'd like it to stay where it is. The whole active graph gets formatted around it, including groups that aren't connected. Your camera, zoom and selection stay put, so you can carry on from where you were.

Pick rounded wires, 45-degree turns or Unreal's own splines. You still get the usual pin colours, hover feedback and execution highlights. Double-click a visible wire to add a normal reroute.

Your connections, pin values and existing reroutes are kept. Comments can resize to fit their nodes, and you can undo a changed layout in one step. Turn GlooPrint off later and your Blueprints still work, with the saved layout and Unreal's usual wires.

It works in Blueprint Event Graphs, functions, macros, Construction Scripts, opened collapsed graphs and graphs made entirely of pure nodes. An Animation Blueprint's ordinary Event Graph works too. Material graphs, animation pose graphs, Niagara, Control Rig and behaviour trees aren't supported.

The C++ source and a setup guide are included. There are no extra plugins to install or services to sign up for. You'll find the wire and spacing settings under Editor Preferences > Plugins > GlooPrint.

A couple of things to know before using it. Very large graphs, or nodes with lots of pins, can take minutes on the first pass and may pause the editor. Some wires use Unreal's usual curves while GlooPrint is still working out a route. Other formatting or wire plugins can also clash with the F shortcut or wire drawing.

This is the UE 5.8 release candidate for Windows and Mac. Windows testing and some large-graph performance work are still to do, so the listing is staying in draft for now.

The gallery shows ordinary Unreal nodes being formatted. The cover is promotional artwork. No game content pack is included.

FAQ
Does F only format the nodes I select?
No, it formats the whole graph you're working in. Selecting a node tells
GlooPrint which one you'd like to keep in place. Groups that aren't connected
get tidied too. Other graphs in the Blueprint are left alone.

Will my Blueprints still work if I turn GlooPrint off?
Yes. The nodes and connections are ordinary Unreal data, so you can keep
editing and using the Blueprint without GlooPrint. Your saved layout stays,
and the wires go back to Unreal's usual curves.
