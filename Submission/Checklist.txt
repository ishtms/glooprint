PACKAGE CONTENTS

Use the source ZIP produced by Scripts/PrepareRelease.py. It contains exactly
one GlooPrint folder with GlooPrint.uplugin, Source, Config, Resources and
Documentation. The plugin has no content assets; do not add dummy Content,
Public or ThirdParty folders. The detailed rules prohibit unused directories.
Native automation under Source is retained, guarded by WITH_DEV_AUTOMATION_TESTS.
The separate Tests/ReferenceComparison adapter and sibling commercial plugins
are never included. No .exe/.msi, local binaries, build intermediates or private
development reports belong in the submission (4.3.6.1.e, 4.3.7.3.a).

UAT build output is a local test installation only; it contains binaries and
intermediates that must not be in the reviewer source ZIP. A source-only ZIP
does not prove that either platform was built. ReleaseRecord.json makes that
distinction and hashes every included file.
