GlooPrint - Fab images

GlooPrintThumbnail.jpg is the current Fab thumbnail. It follows the orange
lettering, dark Blueprint background and warm edge lighting of the owner's
OpenPocketBaseSDK cover. The text is GLOOPRINT, PRESS F., TIDY YOUR BLUEPRINTS.
and FOR UNREAL ENGINE. It is promotional artwork made with built-in imagegen,
using the real rounded-wire capture as a reference. It is not a raw screenshot.

The final export is 1920x1080 and 387927 bytes. The generated original was
1672x941, then resampled and exported as JPEG for Fab's upload requirements.
The optional higher-resolution generation returned the same pixel dimensions,
so no extra image detail is claimed. ThumbnailPrompt.txt records the design
prompt. The original is preserved in output/imagegen. The README uses the same
JPEG at assets/glooprint-fab-thumbnail.jpg.

RoundedWires.png and DiagonalWires.png are unchanged native screenshots from
the release-candidate UE 5.8.1 editor run on Mac. Both show the same example
with a different wire style. Each is 3100x1946 and about 0.53 MB. No nodes or
wires were painted over in these gallery images.

The new thumbnail and both gallery images are saved on the Fab draft. The
listing explains that the cover is artwork and the gallery uses ordinary
Unreal nodes. No game content pack is included. The native file picker was
used after the extension upload helper refused local file access. Chrome's
permissions were not changed.

Provenance.json records the sources, dimensions, file sizes and hashes. These
images are uploaded separately to Fab and are not in the plugin source ZIP.
The older assets/glooprint-banner.png remains in the repository, but its
724-pixel height is too small for Fab. Use GlooPrintThumbnail.jpg instead.
